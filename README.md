# 喜宴好味 OMO 電商（banquet-meal-omo）

把婚宴會館宴席上的暢銷菜色製成冷凍調理包，透過**線上商店**與**會館現場**（喜宴桌卡 QR code、門市自取、現場 POS）雙通路銷售，會員、點數、庫存與訂單線上線下整合。

## 技術堆疊
Next.js（App Router）· TypeScript · Tailwind CSS · shadcn/ui · Supabase · 綠界 ECPay · Vercel
